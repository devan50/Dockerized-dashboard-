# Dockerized Dashboard

This is a simple web dashboard I built while learning Docker and DevOps. The project helped me understand how to containerize a web application and run it using Docker Compose.

## Technologies Used

- Python
- HTML
- Docker
- Docker Compose

## Project Structure

```text
devops-dashboard/
├── app.py
├── templates/
│   └── index.html
├── requirements.txt
├── Dockerfile
├── compose.yaml
└── .dockerignore
```

## How to Run

- Building a Docker image for a web application
- Running containers using Docker Compose
- Understanding the basics of containerized applications
- Working with Dockerfiles and application dependencies

- Automate the build and deployment process
- Add application monitoring
- Improve deployment and security practices
